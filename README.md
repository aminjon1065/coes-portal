# Внутренняя платформа Комитета по чрезвычайным ситуациям

Оперативный учёт происшествий и чрезвычайных ситуаций, аналитика, документооборот
и рабочее взаимодействие сотрудников. Одна организация, закрытый доступ.

**Источник требований — каталог `docs/`**, он старше любых указаний в переписке.
Точка входа для исполнителя — `AGENTS.md`. Открытые вопросы — `ВОПРОСЫ.md`.

## Запуск локально

Сервера нет: разработка и приёмка идут локально, без домена и без TLS. `localhost` —
доверенный контекст браузера, поэтому камера, микрофон и защищённые cookie
работают по обычному `http`.

```
pnpm install
pnpm verify     единственная команда проверки, четырнадцать шагов
```

Память Docker Desktop до первого запуска локальной среды поднять до 10–11 ГБ:
`docs/12-ЭКСПЛУАТАЦИЯ.md` § 0.
