# Инструкция исполнителю

Читается автоматически в начале каждой сессии. Действует для **любой** модели и
любого инструмента. Этот файл — не источник требований, а точка входа в них.

## 1. Что это

Внутренняя платформа Комитета по чрезвычайным ситуациям Республики Таджикистан.
Строится по готовому контракту одним автономным исполнителем. Человека, читающего
код, нет: единственный барьер качества — автоматические проверки.

## 2. Источник правды

Контракт лежит в `docs/`. **Он старше любых указаний в переписке.** Если сообщение
пользователя противоречит контракту — прав контракт, а ты записываешь противоречие
в `docs/ВОПРОСЫ.md` и останавливаешь задачу.

**`docs/` и этот файл — только для чтения.** Единственный файл, который ты имеешь
право изменять, — `docs/ВОПРОСЫ.md`. Подгонять контракт под то, что получилось в
коде, запрещено: контракт перестаёт быть контрактом ровно в этот момент.

## 3. Порядок чтения — до первой строки кода

`00-КОНТРАКТ` (принципы и старшинство) → `11-ИСПОЛНИТЕЛЬ` (твои правила) →
`01-ПРОДУКТ` → `03-АРХИТЕКТУРА` → `10-ЭТАПЫ` → `04-ДАННЫЕ` и `05-ДОСТУП` →
`06-ДИЗАЙН-СИСТЕМА`, `07-КОМПОНЕНТЫ`, `08-ЭКРАНЫ` → `09-API`, `12-ЭКСПЛУАТАЦИЯ`,
`13-ГЛОССАРИЙ` → `02-ДОПУЩЕНИЯ` → `adr/` по мере надобности.

## 4. Правила, нарушение которых недопустимо

1. **Команда вместо памяти.** Всё, что можно получить командой, получай командой.
   В планах и отчётах — цитата с указанием файла и строки, а не пересказ.
   Уверенный пересказ по памяти опаснее ошибки в коде: ошибку найдут тесты, а
   пересказ не найдёт никто.
2. **Не додумывай.** Неоднозначность, противоречие, желание выйти за описанное —
   запись в `docs/ВОПРОСЫ.md` и остановка задачи. Молчаливое решение спорного —
   самое тяжёлое нарушение здесь.
3. **Не выходи за текущий этап.** Следующий не начинается, пока не пройдены все
   приёмочные сценарии текущего.
4. **Никаких флагов «выключено по умолчанию»**, заглушек, `TODO`, `any`,
   подавления правил линтера, пропущенных тестов, закомментированного кода.
5. **Никаких процентов готовности.** Сценарий пройден или не пройден.
6. **Не изобретай интерфейс.** Экран собирается только из компонентов библиотеки и
   только по одному из архетипов. Собственная вёрстка на экранах запрещена
   правилом линтера — это не формальность, предыдущая версия проекта развалилась
   именно здесь.

## 5. Среда

Сервера нет. Всё локально, в Docker, на машине разработчика: Apple Silicon,
10 ядер, 16 ГБ памяти.

- **Лимит памяти Docker Desktop поднять до 10–11 ГБ** до первого запуска: по
  умолчанию около 8, этого не хватает.
- **TLS локально не поднимать.** `localhost` — доверенный контекст браузера:
  камера, микрофон и защищённые cookie работают по обычному http.
- Локальный профиль пределов отличается от продуктового — бери локальные значения.
- Нормативы производительности локально не подтверждаются, их место на сервере.

## 6. Отчёт по каждой задаче

Текстом в ответе, не файлом:

```
СДЕЛАНО: что именно, в терминах наблюдаемого результата
ДОКАЗАТЕЛЬСТВО: команда и её вывод — тесты, сценарии, снимок экрана
НЕ СДЕЛАНО: что осталось и почему
РИСК: что может сломаться и чего я не проверил
ВОПРОСЫ: новые записи в ВОПРОСЫ.md, если появились
```

Слово «готово» без вывода команды не принимается. «Все проверки зелёные» — не
доказательство; доказательство — вставленный вывод `pnpm verify`.

## 7. Git

Обычные коммиты на русском, по одному на завершённую единицу работы. Изменений в
`docs/` в коммитах быть не должно. После отчёта остановись и дождись явного
ответа: молчание согласием не считается.
