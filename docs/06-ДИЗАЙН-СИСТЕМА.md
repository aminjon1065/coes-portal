# 06. Дизайн-система

Этот документ существует по одной причине: предыдущая попытка развалилась визуально, потому что композиционные решения принимались заново на каждом экране. Здесь заданы **точные величины**. Исполнителю нечего выбирать.

**Правило чтения.** Если величина не указана в этом документе или в `07-КОМПОНЕНТЫ.md` — её нельзя придумать. Нужно завести вопрос в `ВОПРОСЫ.md` и остановить задачу.

---

## 1. Пять принципов визуального языка

1. **Плотность важнее воздуха.** Это рабочий инструмент оперативной службы, а не витрина. На экране должно помещаться много строк.
2. **Спокойный цвет.** Цвет несёт смысл: важность, состояние, действие. Декоративного цвета не существует.
3. **Одна тема.** Только светлая. Тёмной темы нет и не планируется: она удваивает число состояний каждого компонента, а работа ведётся в освещённых кабинетах и печатается на бумаге.
4. **Ничего не двигается без причины.** Движение сообщает о появлении и исчезновении, не украшает.
5. **Число читается точно.** Моноширинные цифры, выравнивание по правому краю, явное различие нуля и отсутствия данных.

## 3. Типографика

### 3.1. Шрифт

```css
--font-sans: "Noto Sans", "Segoe UI", Arial, sans-serif;
--font-mono: "Noto Sans Mono", Consolas, "Courier New", monospace;
```

Шрифт размещается на своём сервере в формате woff2, подмножество «латиница + кириллица». Внешние шрифты запрещены (`00-КОНТРАКТ.md`). Начертания: 400, 500, 600, 700. **Курсив не используется нигде.**

Приёмочная проверка шрифта: строка `Ғафуров Ӯктам Ҳақназарӣ Ҷумъа қишлоқ` отображается без замещающих прямоугольников (сценарий ПС-0-06).

`font-variant-numeric: tabular-nums` обязателен в: таблицах, плитках показателей, полях ввода чисел, ленте журнала, координатах, сроках. Без него столбцы чисел «пляшут».

### 3.4. Длина строки

Текстовый блок (описание, пояснение, содержание документа) — не шире **90 символов**. Достигается ограничением ширины контейнера, а не переносами.

## 5. Движение

| Токен | Значение | Где |
|---|---|---|
| `--dur-1` | 120 ms | Наведение, нажатие, смена цвета |
| `--dur-2` | 180 ms | Выпадающие списки, вкладки, раскрытие |
| `--dur-3` | 240 ms | Диалоги, боковые панели |
| `--ease` | `cubic-bezier(0.2, 0, 0, 1)` | Все переходы |

При `prefers-reduced-motion: reduce` все длительности равны 0 ms.

Анимация длиннее 240 ms запрещена. Бесконечно повторяющаяся анимация запрещена, кроме кольцевого индикатора загрузки.

## 8. Форматы данных

| Что | Формат | Пример |
|---|---|---|
| Дата | `дд.ММ.гггг` | `08.09.2026` |
| Дата и время | `дд.ММ.гггг ЧЧ:мм` | `08.09.2026 14:35` |
| Дата, время, секунды (только журнал) | `дд.ММ.гггг ЧЧ:мм:сс` | `08.09.2026 14:35:07` |
| Период | `дд.ММ.гггг — дд.ММ.гггг` | `01.01.2026 — 31.03.2026` |
| Целое число | Разряды через узкий неразрывный пробел (U+202F) | `1 234 567` |
| Дробное число | Запятая как разделитель | `12,5` |
| Деньги | Число + ` смн` | `1 234 567,89 смн` |
| Проценты | Число + неразрывный пробел + `%` | `12,5 %` |
| Координаты, градусы | 5 знаков после запятой | `38,55980° с. ш., 68,78700° в. д.` |
| Координаты, градусы-минуты-секунды | Переключателем | `38°33′35,3″ с. ш., 68°47′13,2″ в. д.` |
| Размер файла | КБ, МБ, ГБ, один знак | `12,4 МБ` |
| Длительность | `Ч ч М мин`, менее часа — `М мин`, менее минуты — `С с` | `1 ч 24 мин` |
| **Нет данных** | `—` (U+2014) | `—` |
| **Ноль** | `0` | `0` |

**Пустая ячейка запрещена.** Пустое место неотличимо от сбоя отрисовки. Отсутствие данных обозначается только знаком `—`.

**Различие `—` и `0` обязательно.** На нём стоит вся статистика: «погибших нет» и «данных о погибших нет» — разные утверждения.

**Относительное время («2 часа назад») запрещено** в оперативных данных: дежурному нужна точная отметка. Единственное исключение — переписка, где перед точным временем показывается «Сегодня» или «Вчера».

## 9. Правила текста интерфейса

1. Обращение на «вы» со строчной буквы.
2. Кнопка — глагол в неопределённой форме: «Сохранить», «Зарегистрировать», «Отменить», «Закрыть событие». Запрещены «ОК», «Готово», «Применить изменения», «Продолжить» без указания действия.
3. Заголовки — без точки в конце. Подписи полей — без двоеточия.
4. Сообщение об ошибке — **два предложения: что случилось и что делать**. Пример: «Номер 12/2026 уже присвоен другому документу. Обновите страницу и повторите.»
5. Запрещены: восклицательные знаки, «пожалуйста», «упс», «что-то пошло не так», смайлы, многоточия в конце.
6. Запрещены англицизмы там, где есть русское слово: «имя пользователя», а не «логин»; «панель», а не «дашборд»; «выгрузка», а не «экспорт»; «уведомление», а не «нотификация». Слова «фильтр», «карточка», «реестр», «шаблон» допустимы.
7. Заголовок числовой колонки содержит единицу измерения через запятую: «Погибло, чел.», «Ущерб, смн», «Площадь, га».
8. Сокращения в таблицах — только из перечня в `07-КОМПОНЕНТЫ.md` § Сокращения.
9. Одно понятие — одно слово во всём интерфейсе (`13-ГЛОССАРИЙ.md`).

## 10. Состояния экрана и области данных

Семь состояний. Для каждой области, отображающей данные, обязаны быть определены все семь. **Область, для которой не описано поведение при ошибке, будет реализована без обработки ошибки** — поэтому определения даны здесь, а не оставлены на усмотрение.

| № | Состояние | Когда | Что показывается |
|---|---|---|---|
| 1 | **Загрузка** | Запрос выполняется | Скелет, повторяющий структуру содержимого (для таблиц и карточек), либо кольцевой индикатор (для неизвестной структуры). Появляется, **только если ожидание превысило 300 мс** |
| 2 | **Пусто** | Данных нет и условий отбора нет | Значок 32 px, заголовок, одно пояснение, кнопка основного действия, если оно доступно |
| 3 | **Ничего не найдено** | Данных нет, но заданы условия отбора | Значок, заголовок «Ничего не найдено», пояснение «Измените условия отбора», кнопка «Сбросить условия». **Отличается от «Пусто»** |
| 4 | **Ошибка** | Запрос не удался | Значок 32 px, текст ошибки по § 9.4, `requestId` шрифтом `--t-small` цветом `--c-n-600`, кнопка «Повторить» |
| 5 | **Нет прав** | `403 ACCESS_DENIED` | Значок замка, текст по `05-ДОСТУП.md` § 7. **Кнопки «Повторить» нет** |
| 6 | **Частичный отказ** | Часть данных не загрузилась | Загруженные данные показываются; сверху баннер с пояснением, какая часть недоступна, и кнопкой «Повторить» |
| 7 | **Только чтение** | Объект закрыт, аннулирован или уничтожен | Поля показываются **как текст**, а не как отключённые поля ввода. Сверху баннер с указанием причины |

**Ошибка никогда не скрывается.** Молчаливое отображение пустого экрана вместо неудавшегося запроса — дефект.

## 11. Печать

- Отдельная таблица стилей `print.css`. Печать поддерживается для: карточки события, реестра, суточной сводки, карточки документа, журнала регистрации, ленты журнала действий.
- Скрываются: боковое меню, шапка, кнопки, панель фильтров, элементы навигации.
- Формат A4, книжная ориентация; реестр — альбомная. Поля 15 мм.
- Заголовок таблицы повторяется на каждой странице.
- Колонки, не помещающиеся по ширине, переносятся на дополнительные страницы; обрезка запрещена.
- Нижний колонтитул: наименование системы, дата и время печати, фамилия и должность напечатавшего, номер страницы из общего числа.
- Печать реестра ограничена значением `LIMIT_LIST_PAGE_SIZE`; для большего объёма используется отчёт.

## 12. Доступность

| Требование | Величина |
|---|---|
| Контраст текста к фону | не менее 4,5:1 |
| Контраст границ элементов управления и значков | не менее 3:1 |
| Обводка фокуса | `outline: 2px solid var(--c-focus); outline-offset: 2px` |
| Управление с клавиатуры | Все действия доступны без мыши |
| Порядок обхода | Совпадает с визуальным порядком |
| Подпись поля | Обязательна. `placeholder` подписью не является |
| Диалог | Захватывает фокус, закрывается клавишей Esc, возвращает фокус вызвавшему элементу |
| Цвет | Не единственный носитель смысла |

Убирать `outline` запрещено. Проверка: `axe-core` на каждом экране, ноль нарушений уровня `serious` и `critical`.

## 13. Список запретов

Нарушение любого пункта — дефект, а не предмет обсуждения.

1. Цвет, не объявленный в § 2.
2. Шрифт, отличный от Noto Sans и Noto Sans Mono.
3. Размер шрифта вне шкалы § 3.2.
4. Отступ вне шкалы § 4.1.
5. Тень, отличная от трёх в § 4.6.
6. Скругление вне § 4.5.
7. Градиенты любого вида.
8. Курсивное начертание.
9. Преобразование регистра (`text-transform`).
10. Анимация длиннее 240 ms; бесконечная анимация, кроме индикатора загрузки.
11. Атрибут `style` в разметке.
12. `!important`.
13. Встроенные HTML-элементы в `screens/**` и `features/**` (`00-КОНТРАКТ.md` § П-3).
14. Модальное окно поверх модального окна.
15. Горизонтальная прокрутка страницы. Прокрутка допустима только внутри таблицы или карты.
16. Более двух кнопок основного действия на экране.
17. Всплывающее сообщение для ошибки, требующей действия пользователя: такая ошибка показывается на месте.
18. Пустая ячейка вместо `—`.
19. Относительное время в оперативных данных.

22. Текстовый блок шире 90 символов.
23. Числовая колонка, выровненная не по правому краю.
24. Скрытие неудавшегося запроса.
25. Тёмная тема.
26. Собственная вёрстка на экране вместо архетипа и компонентов.

## 14. Витрина компонентов

Страница `/__ui`, доступная только при `NODE_ENV !== 'production'` **и** обладателю разрешения `sys.status.read`.

Требования:

1. Показывает **каждый** компонент библиотеки во **всех** его состояниях, перечисленных в `07-КОМПОНЕНТЫ.md`.
2. Показывает всю палитру с указанием токена и вычисленного контраста к белому.
3. Показывает всю типографическую шкалу на строке с таджикскими буквами.
4. Показывает все семь состояний области данных из § 10.
5. Не содержит интерактивных настроек: это эталон для сравнения снимков, а не игровая площадка.

Снимки экрана витрины сравниваются с эталоном при каждой проверке (`test:visual`), допуск — 0,1 % площади. Изменение эталона допускается только вместе с изменением этого документа.

## 15. Механизмы проверки

| Что проверяется | Чем |
|---|---|
| Отсутствие встроенных элементов и атрибута `style` в экранах | ESLint `coes/no-intrinsic-jsx` |
| Отсутствие цветов, размеров и отступов вне токенов | `stylelint` с правилом «только `var(--...)` в свойствах цвета, размера шрифта, отступа, скругления и тени» |
| Отсутствие `!important` | `stylelint` |
| Соответствие витрины эталону | `test:visual`, допуск 0,1 % |
| Контраст и доступность | `test:a11y` (axe-core) |
| Наличие всех семи состояний у области данных | Проверка `test:e2e`: для каждого реестра и карточки принудительно вызываются состояния 1–6 подменой ответа сервера |
