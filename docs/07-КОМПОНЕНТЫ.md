# 07. Библиотека компонентов

Все компоненты живут в `packages/ui`. **Это единственное место, где разрешены встроенные HTML-элементы и собственные стили.** Экраны собираются только из компонентов этого каталога (`00-КОНТРАКТ.md` § П-3).

**Правило.** Компонента, которого здесь нет, не существует. Если экрану нужен компонент, отсутствующий в каталоге, — это вопрос Держателю контракта, а не повод написать вёрстку.

Ниже для каждого компонента указаны: назначение, свойства, точные размеры, **все состояния**. Компонент, для которого не описано поведение при ошибке, будет реализован без обработки ошибки, поэтому состояния перечислены полностью и явно.

---

## 1. Общие правила

1. Имя компонента в коде — латиницей (`Button`), в этом документе — по-русски. Соответствие приведено у каждого компонента.
2. Каждый компонент принимает `id` и передаёт неиспользованные атрибуты доступности на корневой элемент.
3. Компонент **никогда** не задаёт себе внешние отступы (`margin`). Расстояние между компонентами задаёт `Стек` или `Сетка`.
4. Компонент **никогда** не обращается к серверу. Данные приходят свойствами.
5. Ширина по умолчанию — по содержимому; растяжение включается свойством `растянуть`.
6. Каждый интерактивный компонент имеет пять базовых состояний: обычное, наведение, фокус, нажатие, отключено. Далее перечислены только отличия и дополнительные состояния.
7. Отключённое состояние: цвет текста `--c-n-400`, фон `--c-n-50`, курсор `not-allowed`, обязательна подсказка с причиной.

## 4. Компоненты раскладки

### 4.1. Стек — `Stack`

Единственный способ расположить элементы друг за другом и задать между ними расстояние.

| Свойство | Значения | По умолчанию |
|---|---|---|
| `направление` | `вертикально` \| `горизонтально` | `вертикально` |
| `отступ` | токен шкалы `sp-05`…`sp-16` | `sp-4` |
| `выравнивание` | `начало` \| `центр` \| `конец` \| `растянуть` | `растянуть` |
| `распределение` | `начало` \| `центр` \| `конец` \| `между` | `начало` |
| `переносить` | да \| нет | нет |

Состояния: нет. Произвольное числовое значение отступа передать нельзя — только токен.

### 4.2. Сетка — `Grid`

12 колонок, промежуток 16 px.

| Свойство | Значения |
|---|---|
| `колонок` | 1…12 (на широком экране) |
| `колонокСредний` | 1…12 (ниже `--bp-md`) |
| `колонокУзкий` | 1…12 (ниже `--bp-sm`), по умолчанию 1 |

Дочерний элемент занимает 1 колонку; занять несколько — свойством `занять` у `GridItem`.

### 4.3. Панель — `Panel`

Поверхность с необязательным заголовком и рядом действий.

| Свойство | Значения |
|---|---|
| `заголовок` | текст |
| `подзаголовок` | текст |
| `действия` | компоненты кнопок |
| `отступ` | `нет` \| `sp-4` \| `sp-6`; по умолчанию `sp-6` |
| `сворачивается` | да \| нет |

Размеры: фон `--c-surface`, граница 1 px, скругление `--r-3`, тень `--sh-1`. Высота заголовка 48 px, текст `--t-h4`.

Состояния: обычное, свёрнутое, загрузка (скелет вместо содержимого), ошибка (состояние 4 внутри панели).

### 4.4. Секция — `Section`

Заголовок группы полей внутри формы. Без фона и границы.

Заголовок `--t-h4`, отступ снизу 12 px, разделитель `--c-n-200` под заголовком.

### 4.5. Разделитель — `Divider`

Горизонтальная или вертикальная линия 1 px цвета `--c-border`. Свойство `отступ` из шкалы.

### 4.6. Полоса действий — `Toolbar`

Ряд кнопок и полей, прижатый к верху области содержимого. Высота 48 px, отступ между элементами 8 px, при нехватке ширины лишние действия уходят в меню `more-horizontal`.

## 5. Компоненты навигации

### 5.1. Боковое меню — `SideNav`

| Свойство | Значения |
|---|---|
| `разделы` | перечень: значок, наименование, адрес, счётчик |
| `свёрнуто` | да \| нет |

Размеры: ширина 248 px (56 px свёрнуто), фон `--c-p-800`, текст `--c-n-0`, строка 36 px, значок 20 px, отступ 12 px.

Состояния строки: обычное, наведение (фон `rgba(255,255,255,.08)`), текущее (фон `rgba(255,255,255,.14)`, левая полоса 3 px цвета `--c-n-0`), отключено (раздел недоступен по правам — **строка не отображается вовсе**, а не отключается).

Счётчик непрочитанного — компонент `Счётчик` справа.

### 5.2. Шапка — `TopBar`

Высота 52 px, фон `--c-surface`, нижняя граница 1 px.

Состав слева направо: кнопка сворачивания меню, наименование текущего раздела, поле общего поиска (ширина 320 px, скрывается ниже `--bp-md`), **переключатель должности**, значок уведомлений со счётчиком, меню профиля.

Переключатель должности: показывает наименование должности и подразделения; если назначение одно — показывает их же без возможности переключения; при действующем замещении добавляется строка «Замещает: <должность>, приказ №<номер>».

Состояния: обычное, открыт список должностей, открыт список уведомлений, открыто меню профиля.

### 5.3. Хлебные крошки — `Breadcrumbs`

Текст `--t-small`, цвет `--c-n-600`, разделитель `chevron-right` 16 px. Последний элемент не является ссылкой. Более пяти уровней сворачиваются в многоточие с меню.

### 5.4. Вкладки — `Tabs`

Высота 36 px, текст `--t-body`, активная вкладка — нижняя полоса 2 px цвета `--c-p-500` и начертание 600.

Состояния: обычная, наведение, активная, отключена (с подсказкой о причине), со счётчиком.

При нехватке ширины вкладки прокручиваются горизонтально внутри своей полосы; страница не прокручивается.

### 5.5. Постраничная навигация — `Pagination`

Показывает: «Показано 1–50 из 1 234», выбор размера страницы (25, 50, 100, 200), кнопки «Назад» и «Далее».

Если общее число превышает 10 000, вместо точного значения выводится «более 10 000» (`09-API.md` § Постраничный вывод).

Состояния: обычное, первая страница (кнопка «Назад» отключена), последняя страница, загрузка (кнопки отключены), общее число неизвестно.

## 6. Компоненты отображения данных

### 6.1. Таблица — `Table`

Главный компонент системы. Используется во всех реестрах.

| Свойство | Значения |
|---|---|
| `колонки` | описание колонок (см. ниже) |
| `строки` | данные |
| `плотность` | `компактная` (36 px) \| `обычная` (44 px); по умолчанию компактная |
| `выбор` | `нет` \| `одиночный` \| `множественный` |
| `сортировка` | поле и направление |
| `состояние` | `данные` \| `загрузка` \| `пусто` \| `ненайдено` \| `ошибка` \| `нетправ` |
| `наСтроку` | действие по нажатию на строку |
| `закреплённыеКолонки` | число колонок слева |

Описание колонки: ключ, заголовок, вид (`текст` \| `число` \| `дата` \| `датавремя` \| `метка` \| `важность` \| `состояние` \| `действия`), ширина (`авто` \| фиксированная в px), выравнивание, сортируемость, обязательность отображения.

Размеры: заголовок 40 px, фон заголовка `--c-n-100`, текст заголовка `--t-body-strong` цвета `--c-n-700`; строка 36 px, нечётные строки `--c-n-25`; внутренний отступ ячейки 12 px; граница между строками 1 px.

**Обязательные правила:**
- Колонка вида `число` выравнивается по правому краю **всегда**, с `tabular-nums`.
- Отсутствующее значение — `—`, не пустая ячейка.
- Текст, не помещающийся в ячейку, обрезается многоточием, полное значение — во всплывающей подсказке.
- Горизонтальная прокрутка — **внутри** таблицы; страница не прокручивается.
- Ниже `--bp-sm` таблица переходит в режим карточек: одна запись — одна карточка, показываются только колонки с признаком обязательности.

Состояния: `данные`, `загрузка` (скелет из 10 строк), `пусто`, `ничего не найдено`, `ошибка`, `нет прав`, `загрузка следующей страницы` (нижняя строка со скелетом), `строка выделена`, `строка отмечена`, `сортировка по колонке`.

### 6.2. Список описаний — `DescriptionList`

Пары «подпись — значение» в карточке объекта.

Раскладка: две колонки, подпись `--t-caption` цвета `--c-n-600` шириной 200 px, значение `--t-body`. Ниже `--bp-sm` — одна колонка, подпись над значением.

Состояния: значение есть, значение отсутствует (`—`), значение скрыто по правам (текст «Нет доступа» цветом `--c-n-500` со значком `lock`), загрузка (скелет).

### 6.3. Плитка показателя — `MetricTile`

| Свойство | Значения |
|---|---|
| `подпись` | текст |
| `значение` | число |
| `единица` | текст |
| `изменение` | число и направление относительно прошлого периода |
| `важность` | `sev-1`…`sev-5` или отсутствует |
| `переход` | адрес реестра с применёнными условиями отбора |

Размеры: высота 96 px, отступ 16 px, значение `--t-metric`, подпись `--t-caption`, изменение `--t-small` со значком `arrow-up`/`arrow-down`.

Состояния: обычное, загрузка (скелет), нет данных (`—` вместо числа), ошибка (значок `alert-circle` и текст «Не удалось получить»), нет прав, с переходом (курсор указателя, обводка при наведении).

**Рост показателя не окрашивается в зелёный автоматически.** Рост числа погибших — не успех. Направление изменения показывается стрелкой и нейтральным цветом; окраска задаётся свойством `хорошееНаправление`, которое обязательно указывается явно.

### 6.4. График — `Chart`

Разрешены **пять** видов, других не существует: `линия`, `столбцы`, `столбцы-стопкой`, `горизонтальные столбцы`, `площадь`.

**Круговые, кольцевые, лепестковые и любые трёхмерные диаграммы запрещены**: они плохо читаются и не позволяют сравнивать величины.

| Свойство | Значения |
|---|---|
| `вид` | один из пяти |
| `ряды` | данные |
| `подписьX`, `подписьY` | текст с единицей измерения |
| `высота` | 240 \| 320 \| 400 px |
| `легенда` | `сверху` \| `снизу` \| `нет` |

Цвета рядов — фиксированная последовательность из палитры: `--c-p-500`, `#17703F`, `#A85A12`, `#6E1410`, `--c-n-600`, `--c-p-300`. Более шести рядов не выводится: остальные объединяются в «Прочие».

Настройки библиотеки графиков не передаются из экранов. Экран передаёт только перечисленные свойства.

Состояния: данные, загрузка (скелет высотой графика), нет данных, ошибка, нет прав.

### 6.5. Карта — `MapView`

| Свойство | Значения |
|---|---|
| `объекты` | точки, линии, полигоны |
| `слои` | перечень слоёв с признаком видимости |
| `режим` | `просмотр` \| `выборТочки` \| `выборОбласти` |
| `центр`, `масштаб` | начальное положение |
| `форматКоординат` | `градусы` \| `градусы-минуты-секунды` |

Обязательные элементы: панель слоёв справа (сворачиваемая), масштабная линейка, показ координат под курсором, кнопки увеличения и уменьшения, кнопка «Показать всё», указание источника подложки.

Адрес подложки берётся из настройки `MAP_STYLE_URL` (`03-АРХИТЕКТУРА.md`). Экран источник подложки не выбирает.

Состояния:
- `данные` — подложка и объекты загружены;
- `загрузка` — кольцевой индикатор поверх серого фона;
- **`подложка недоступна`** — объекты, слои, масштабная линейка и координаты отображаются на однотонном фоне `--c-n-100` с сеткой координат; сверху баннер «Картографическая подложка недоступна. Объекты и координаты отображаются без фоновой карты.» **Это не ошибка и не пустой экран**;
- `нет объектов` — подложка есть, объектов нет, надпись по центру;
- `превышен предел` — показаны первые `LIMIT_MAP_FEATURES` объектов, баннер с пояснением;
- `ошибка` — не удалось получить объекты;
- `нет прав`.

### 6.9. Аватар — `Avatar`

Круг 24 / 32 / 40 px. При отсутствии изображения — инициалы на фоне `--c-n-200`, текст `--c-n-700`. Цвет фона не зависит от имени: случайная раскраска людей запрещена.

### 6.10. Счётчик — `Counter`

Кружок `--r-full`, высота 18 px, минимальная ширина 18 px, текст `--t-caption` 600. Более 99 показывается как `99+`. Нулевое значение — компонент не отображается.

### 6.11. Лента журнала — `AuditFeed`

Показывает записи журнала действий по объекту (`05-ДОСТУП.md` § 9.4).

Состояния: данные, загрузка, пусто («Изменений не было»), ошибка, нет прав, загрузка предыдущих записей.

Изменения полей персональных данных в ленте показываются как «Изменены сведения о пострадавшем» **без значений**, если у смотрящего нет разрешения уровня 2.

## 7. Компоненты ввода

### 7.1. Поле — `Field`

Обёртка любого элемента ввода. **Элемент ввода без `Field` использовать запрещено**: иначе поле останется без подписи.

| Свойство | Значения |
|---|---|
| `подпись` | текст, обязательно |
| `обязательное` | да \| нет |
| `подсказка` | текст под полем |
| `ошибка` | текст ошибки |
| `состояние` | `обычное` \| `ошибка` \| `отключено` \| `тольконачтение` |

Раскладка: подпись `--t-caption` цвета `--c-n-700`, отступ 4 px, элемент ввода, отступ 4 px, подсказка или ошибка `--t-small`.

Обязательность обозначается знаком `*` цвета `--c-danger-600` после подписи. Пояснение «Поля со звёздочкой обязательны» выводится один раз вверху формы.

Состояние `тольконачтение` показывает **значение как текст** (`--t-body`, цвет `--c-n-900`), а не отключённое поле ввода.

### 7.2. Ввод текста — `TextInput`

Высота 34 px, граница 1 px `--c-border`, скругление `--r-2`, отступ 10 px, текст `--t-body`.

Состояния: обычное, наведение (граница `--c-border-strong`), фокус (обводка), ошибка (граница `--c-danger-600`), отключено, только чтение, с очисткой (крестик), с ведущим значком, с суффиксом (единица измерения).

`placeholder` используется только для примера формата (`38,55980`), **никогда** вместо подписи.

### 7.3. Ввод многострочного текста — `TextArea`

Минимальная высота 80 px, растёт по содержимому до 320 px, далее прокрутка. Счётчик символов показывается, только если задано ограничение длины, и появляется при остатке менее 20 % от предела.

### 7.4. Ввод числа — `NumberInput`

Выравнивание по правому краю, `tabular-nums`. Разделитель разрядов проставляется при потере фокуса; при вводе не мешает. Десятичный разделитель — запятая; точка при вводе автоматически заменяется на запятую.

Свойства: `минимум`, `максимум`, `знаковПослеЗапятой`, `единица` (выводится суффиксом внутри поля справа).

Состояния: базовые, плюс «значение вне допустимого диапазона» с текстом «Допустимо от N до M».

**Пустое поле означает «нет данных», а введённый ноль означает ноль.** Компонент обязан различать их и передавать `null` и `0` соответственно.

### 7.5. Ввод даты — `DateInput`

Ввод с клавиатуры в формате `дд.ММ.гггг` и выбор в календаре. Свойство `сВременем` добавляет `ЧЧ:мм`.

Календарь: неделя начинается с понедельника, выходные не выделяются цветом (рабочие дни оперативной службы), сегодняшний день обведён, недоступные даты приглушены.

Состояния: базовые, «дата вне допустимого диапазона», «неверный формат» (текст «Введите дату в формате дд.мм.гггг»).

### 7.6. Ввод периода — `DateRangeInput`

Два поля даты и набор готовых периодов: «Сегодня», «Вчера», «7 дней», «Текущий месяц», «Прошлый месяц», «Квартал», «Год», «Произвольный». Проверка: конец не раньше начала.

### 7.7. Выбор — `Select`

Список значений с поиском при числе элементов более 10. Высота элемента списка 32 px, максимальная высота списка 320 px, далее прокрутка.

Состояния: закрыт, открыт, поиск без результатов («Ничего не найдено»), загрузка списка, ошибка загрузки («Не удалось загрузить список», кнопка «Повторить»), отключено, только чтение, множественный выбор (значения — метками с крестиками).

### 7.8. Выбор из справочника — `CatalogSelect`

Разновидность `Select`, работающая со справочником по его коду. Показывает только действующие элементы (`is_active`, `valid_from`/`valid_to` относительно **даты события**, а не текущей). Иерархический справочник выводится деревом с отступом 16 px на уровень.

Если у элемента задан уровень важности, слева от наименования выводится точка соответствующего цвета.

Состояния: как у `Select`, плюс «выбранный элемент более не действует» — элемент показывается с пометкой «(не действует)» и не удаляется из значения.

### 7.9. Выбор сотрудника — `PersonSelect`

Поиск по фамилии с учётом таджикских букв. В строке: фамилия и инициалы, должность, подразделение. Показываются только сотрудники в области видимости.

### 7.10. Выбор подразделения — `OrgUnitSelect`

Дерево подразделений с поиском. Свойство `включаяНижестоящие` добавляет флажок «и все нижестоящие». Показываются только подразделения в области видимости.

### 7.11. Флажок — `Checkbox`

Размер 16 px, область нажатия 32 px, подпись справа `--t-body`. Состояния: снят, установлен, частично установлен, отключён, ошибка.

### 7.12. Радиогруппа — `RadioGroup`

Круг 16 px, расстояние между вариантами 8 px. Используется при 2–5 вариантах; при большем числе — `Select`.

### 7.13. Переключатель — `Switch`

Ширина 36 px, высота 20 px. Используется **только** для настроек, вступающих в силу немедленно. Для полей формы, сохраняемых кнопкой, используется `Checkbox`.

### 7.14. Загрузка файлов — `FileUpload`

Область перетаскивания высотой 96 px, кнопка «Выбрать файлы», перечень загруженных.

Строка файла: значок по типу, имя, размер, состояние, кнопка удаления.

Состояния файла: ожидание, загрузка (полоса с процентом — единственное место, где допустим процент, потому что это доля переданных байтов, а не готовность работы), загружен, ошибка (текст причины: превышен размер, недопустимый тип, отклонён проверкой, недостаточно места на диске), удалён.

Ограничения из реестра пределов: `LIMIT_UPLOAD_SIZE_MB`, `LIMIT_ATTACHMENTS_PER_CARD`, `LIMIT_DISK_FREE_GB`. При достижении любого — отказ с точным текстом из реестра.

### 7.15. Выбор точки на карте — `MapPointInput`

Карта высотой 320 px в режиме `выборТочки` плюс два поля координат. Ввод координат вручную перемещает точку; перемещение точки обновляет поля. Кнопка «Очистить» снимает точку.

Состояния: точка не задана, точка задана, подложка недоступна (точка задаётся по координатам, карта — фон с сеткой), координаты вне допустимых пределов (широта −90…90, долгота −180…180).

### 7.16. Панель условий отбора — `FilterBar`

Строка над таблицей. Состав: поле поиска, до четырёх часто используемых условий, кнопка «Ещё условия», открывающая боковую панель со всеми условиями, метки применённых условий, кнопка «Сбросить».

Обязательно: **применённые условия видны всегда** метками. Скрытое условие отбора, из-за которого пользователь не видит данные, — дефект.

Сохранение набора условий — кнопка «Сохранить отбор»; сохранённые отборы доступны в выпадающем списке (`analytics.saved_view`).

## 8. Компоненты действий

### 8.1. Кнопка — `Button`

| Вид | Фон | Текст | Граница | Где |
|---|---|---|---|---|
| `основная` | `--c-p-500` | `--c-n-0` | нет | Главное действие экрана. Не более одной в области |
| `обычная` | `--c-n-0` | `--c-n-800` | 1 px `--c-border` | Прочие действия |
| `тихая` | прозрачный | `--c-n-700` | нет | Действия в строках таблиц, в полосе действий |
| `опасная` | `--c-n-0` | `--c-danger-600` | 1 px `--c-danger-600` | Удаление, аннулирование, уничтожение |

Размеры: малая 28 px, обычная 34 px, крупная 40 px. Значок 16 px, отступ до текста 8 px.

Состояния: обычное, наведение, фокус, нажатие, отключено (с обязательной подсказкой о причине), **выполняется** (значок `loader-2` вращается, текст сохраняется, кнопка недоступна для повторного нажатия).

Кнопка, запускающая изменение данных, **обязана** переходить в состояние «выполняется» и блокироваться до ответа. Иначе двойное нажатие создаст две записи.

Кнопка «опасная» всегда открывает `ДиалогПодтверждения`.

### 8.2. Кнопка-значок — `IconButton`

Квадрат 28 / 34 px, значок 16 px. **Обязательны** `aria-label` и всплывающая подсказка. Кнопка-значок без подписи и подсказки запрещена (`06-ДИЗАЙН-СИСТЕМА.md` § 13).

### 8.3. Группа кнопок — `ButtonGroup`

Кнопки без промежутка, общая граница, скругление только по краям. Используется для переключения представления (таблица / карта / таблица и карта).

### 8.4. Меню — `Menu`

Выпадающий список действий. Ширина от 180 px, строка 32 px, тень `--sh-2`, скругление `--r-2`. Разделы отделяются `Divider`. Опасные действия — в конце, цветом `--c-danger-600`.

Состояния: закрыто, открыто, элемент отключён (с подсказкой), пусто (нет доступных действий — кнопка меню не отображается).

## 9. Компоненты обратной связи

### 9.1. Скелет — `Skeleton`

Прямоугольник `--c-n-100` со скруглением `--r-2` и мягким пульсированием 1200 ms (единственная разрешённая бесконечная анимация помимо `loader-2`). Появляется, только если ожидание превысило 300 ms.

Скелет **повторяет структуру будущего содержимого**: для таблицы — строки нужной высоты, для карточки — блоки полей. Прямоугольник вместо всего экрана запрещён.

### 9.2. Кольцевой индикатор — `Spinner`

Значок `loader-2`, размеры 16 / 24 / 32 px, вращение 800 ms. Применяется внутри кнопок и там, где структура содержимого неизвестна.

### 9.3. Пустое состояние — `EmptyState`

| Свойство | Значения |
|---|---|
| `вид` | `пусто` \| `ненайдено` |
| `заголовок`, `пояснение` | текст |
| `действие` | кнопка |

Размеры: значок 32 px цвета `--c-n-400`, заголовок `--t-h4`, пояснение `--t-lead` цвета `--c-n-600`, вертикальный отступ 48 px.

Вид `пусто`: значок `inbox`, пример «Событий пока нет» / «Зарегистрируйте первое событие» / кнопка «Зарегистрировать событие».
Вид `ненайдено`: значок `search-x`, «Ничего не найдено» / «Измените условия отбора» / кнопка «Сбросить условия».

**Эти два вида не взаимозаменяемы.**

### 9.4. Состояние ошибки — `ErrorState`

Значок `alert-circle` 32 px цвета `--c-danger-600`, заголовок `--t-h4`, текст ошибки `--t-body`, `requestId` шрифтом `--t-small` цвета `--c-n-600` с кнопкой копирования, кнопка «Повторить».

Текст берётся из ответа сервера. Технические подробности и стек вызовов не показываются.

### 9.5. Состояние отсутствия прав — `NoAccessState`

Значок `lock` 32 px цвета `--c-n-500`, заголовок «Нет доступа», текст по `05-ДОСТУП.md` § 7. **Кнопки «Повторить» нет**: повтор ничего не изменит.

### 9.6. Баннер — `Banner`

Полоса с левой акцентной границей 3 px, отступ 12 px, скругление `--r-2`.

Виды: сведение (`--c-p-50`), предупреждение (`--c-warning-50`), ошибка (`--c-danger-50`), успех (`--c-success-50`).

Свойства: значок, заголовок, текст, действие, закрываемость. Баннер о состоянии объекта (аннулировано, только чтение, подложка недоступна) **не закрывается**.

### 9.7. Всплывающее сообщение — `Toast`

Появляется в правом нижнем углу, ширина 360 px, живёт 5 секунд, вручную закрывается.

Применяется **только** для подтверждения успешно выполненного действия («Событие 2026-DUS-0017 зарегистрировано») и для сведений, не требующих реакции.

**Запрещено** использовать для ошибок, требующих действия пользователя: такие показываются на месте, рядом с причиной (`06-ДИЗАЙН-СИСТЕМА.md` § 13, пункт 17).

Одновременно не более трёх; более старые вытесняются.

### 9.8. Диалог — `Dialog`

Ширины: 400 / 560 / 720 / 960 px. Тень `--sh-3`, скругление `--r-4`, подложка `--c-overlay`.

Структура: заголовок `--t-h3` и кнопка закрытия, содержимое с отступом 24 px, полоса кнопок снизу, выровненная вправо.

Правила: захватывает фокус, закрывается по Esc и по нажатию на подложку (кроме диалогов с несохранёнными данными), возвращает фокус вызвавшему элементу. **Диалог поверх диалога запрещён.**

Состояния: открыт, выполняется действие (кнопки заблокированы, основная показывает `loader-2`), ошибка внутри диалога (баннер сверху, диалог не закрывается).

### 9.9. Диалог подтверждения — `ConfirmDialog`

Ширина 400 px. Заголовок — вопрос («Аннулировать событие 2026-DUS-0017?»), текст — последствия («Событие будет исключено из всех показателей. Действие необратимо.»), поле причины, если она обязательна, кнопки «Отмена» и действие видом `опасная`.

Для необратимых действий (уничтожение документа, удаление записи совещания) требуется ввод подтверждающего слова: пользователь набирает регистрационный номер объекта.

### 9.10. Подсказка — `Tooltip`

Тёмный прямоугольник `--c-n-900`, текст `--c-n-0` `--t-small`, отступ 8 px, задержка появления 400 ms, скругление `--r-2`. Максимальная ширина 280 px. Не содержит интерактивных элементов.

### 9.11. Указатель свободного места — `DiskSpaceIndicator`

Полоса с числом: «Свободно 1,2 ТБ из 4 ТБ». Цвет: обычный при запасе более 20 %, предупреждение при 10–20 %, ошибка при менее 10 %. Показывается на экране записей совещаний и на экране состояния сервера.

### 9.12. Предупреждение о недопустимости сведений ограниченного доступа — `RestrictedNotice`

Баннер вида «предупреждение», не закрывается, размещается **над формой** при создании карточки события и документа:

> Не вводите сведения, составляющие государственную тайну. Система для них не предназначена.

Текст задан здесь дословно и изменению без записи о решении не подлежит (Д-18).

### 9.13. Экран несовместимости — `UnsupportedBrowser`

Показывается вместо приложения, если браузер не соответствует требованиям (Д-09).

Содержит: обнаруженные название и версию браузера, перечень поддерживаемых, указание обратиться к системному администратору. **Приложение при этом не загружается**: обломки интерфейса пользователю не показываются.

Проверка выполняется до загрузки основного кода приложения.
